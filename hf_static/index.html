BERT + GPT Balochi App

One project with two sections: multilingual BERT (encoder-only NER) and Balochi GPT/Q&A (decoder-only, low-resource, monolingual).

Live / Source

  • GitHub repo: sajida12-sys/curecauprojiect
  • BERT model repo: sajida12/bert-ner-mbert
  • GPT Balochi model repo: sajida12/gpt2-balochi

What each section does

  • BERT: Named Entity Recognition (Person / Location / Organization). Not sentiment.
  • GPT / Balochi: Balochi-only question answering from the Balochi dataset.

Note about Spaces hosting

Free Hugging Face accounts can host Static Spaces. Running Streamlit/Docker Spaces on free CPU now needs Hugging Face PRO. Use Streamlit Community Cloud with the GitHub repo for the interactive app: share.streamlit.io
